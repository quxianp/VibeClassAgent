# 给 AI Agent 的界面工作须知

你在 **VibeClassAgent** 项目里负责**界面**。后端是 Rust，由另一个 agent 维护。
边界很干净：**只改 `web/`，不碰 `crates/`。**

界面跑在**程序自己的窗口**里（WebView2），不是套壳浏览器。
对你来说是好消息：就是一个 Chromium，HTML/CSS/JS 照旧写。

## 三条硬约束（违反会破坏部署）

1. **产物必须浏览器直接能跑。** 想引构建步骤可以（React / Vite / TS），
   但成果必须落在 `web/` 下、浏览器直接可执行。
   **部署时不会跑 `npm build`** —— 目标机器不装任何运行时，这是项目底线。

2. **`web/index.html` 必须是入口。** 后端靠这个文件名判断前端是否存在，
   改名会静默退回内置旧版本（表现为"改了没效果"，很难查）。

3. **文案不能硬编码中文。** 走 `/api/i18n`，新增文案让后端加进
   `locales/*.json`。写死中文会让英文版缺一块。

## 快速开始

```powershell
cd D:\VibeClassAgent
target\release\vca.exe gui          # 直接弹出程序自己的窗口
```

改完关掉窗口再跑一次就能看到新效果 —— 不用编译、不用等后端。

要用浏览器调试（原生窗口里没有 DevTools）：加 `--no-open`，
再从 `data\logs\ui.log` 里取 `?t=` 后面的令牌。详见 README。

## 自检

```powershell
python scripts\smoke.py     # 必须 58/58 全过
```

打真实 HTTP 接口。接口调用方式要改就找后端商量，
**不要为了让脚本变绿而绕过接口** —— 那种绿是假的。

---

## 后端负责什么（你不用管）

- 你改了 `web/`，后端同步一份到 `crates/vca-gui/src/web/` 再重编译（内置兜底）。
  **改完记得说一声**，否则「exe 单独拷走」会退化成旧界面。
- 加文案、加接口、改返回结构、修后端 bug。
- 路径穿越防护、Content-Type、缓存头 —— 都替你守住了。
