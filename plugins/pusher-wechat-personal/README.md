**插件 id**：`pusher.wechat.personal`
**状态**：占位（框架骨架，未实现）

## 风险提示（必须向用户展示）

本插件使用**非官方**第三方协议实现，v1 会内置并在启用前展示风险确认
（文案见策划书附录 C）。要点：

1. 可能违反对应平台服务协议，存在账号被封禁或功能受限的风险；
2. 依赖第三方项目持续维护，可能因平台风控升级而随时失效；
3. 建议使用小号，不要使用重要账号；
4. 凭据仅保存在本机 `profile` 的 `secrets.env`，不上传任何服务器。
